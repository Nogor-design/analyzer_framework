What This Page Does

Strategy Lab starts from a strategy_spec.json. That file is the strategy picker here: its strategy_name becomes the NinjaScript class and optimizer strategy, and its family chooses the source renderer.

1. Author
Generate or update the NinjaTrader strategy from the spec.
2. Compile/repair
Ask NinjaTrader to compile, then repair errors when the loop can.
3. Optimize
After a clean compile, create an optimizer session and run guardrails.
When to use which page

Use Strategy Lab when you want the loop to author and repair a strategy first. Use the Recipe optimizer when the strategy already exists in NinjaTrader and you only want to generate or run optimizer batches.

Built-in spec families: sma_cross, sma_cross_smoke.
