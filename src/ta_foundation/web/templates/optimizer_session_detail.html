Walk-forward validation (optional)

Re-run each final candidate's fixed-Backtest template across N rolling historical windows. Tests whether the optimized parameters survive in time periods they weren't optimized on. Strictly historical re-validation — does NOT touch any account. Output lands in deployment_package/walkforward/.

Parameter neighborhood (optional)

For each final candidate, re-run its fixed-Backtest template with small ±pct offsets around each numeric optimized parameter. Distinguishes a robust peak from a needle peak in the optimizer's surface. Bool / enum parameters are skipped automatically. Output lands in deployment_package/neighborhood/.
Stability per candidate:
Run Center PF Center net Cells With trades PF>1 PF min PF median PF max Net median CoV(net) Flags
Per-cell detail:
Run Cell Label Trades Net PF DD

Shadow execution (optional)

Re-run each final candidate against a recent rolling-window of historical data. Strictly conservative: it does NOT touch a live account. The shadow templates are fixed Backtests with shifted dates, dispatched through the same NT AddOn as the optimizer phases. Output lands in deployment_package/shadow/.
