# Quick Start: Improved Strategy Discovery

**Updated:** May 27, 2026
**New Features:** Dynamic expansion, cross-family ranking, conditional rules

---

## The 5-Minute Overview

### Old Workflow
```
1. Run stage 1 with minimal params
   → Which family won? (scroll through 250 combos)
   → OK, try candles with TP=[20-100]? (guess)
2. Run stage 2 (manually configured)
   → Check results manually
   → Manually edit stage 3 config
3. Run stage 3
   → Hope params were right
   → If bad, start over
```
**Time: 3-5 hours of manual iteration**

### New Workflow
```
1. Run stage 1 (same as before)
2. AUTO:
   ├─ Ranks all 8 families
   ├─ Identifies which to pursue
   ├─ Auto-expands params based on winners
   └─ Generates stage 2 config
3. Run stage 2 (with auto-generated config)
   → Results are better (expanded params found sweet spot)
4. AUTO:
   ├─ Re-analyzes winners
   ├─ Further expands
   └─ Generates stage 3
5. Run stage 3 (ready to deploy)
```
**Time: 30-45 minutes total (automated, repeatable)**

## Usage: Three Patterns

### Pattern 1: Simple (Just Dynamic Expansion)

```python
# After stage 1 discovery
from ta_foundation.analysis.entry_strategies.dynamic_params import (
    recommend_param_expansion,
    generate_expanded_config,
)
import yaml

# Load stage 1 results
stage1_results = discovery_output["sweep_results"]

# Get recommendations
rec = recommend_param_expansion(stage1_results, expansion_factor=1.5)
print(rec["summary"])  # "3 families exceed PF >= 1.2"

# Generate stage 2 config
with open("discovery/01_quick_scan.yaml") as f:
    stage1_cfg = yaml.safe_load(f)

stage2_cfg = generate_expanded_config(stage1_cfg, stage1_results)

# Save and run stage 2
with open("discovery/02_quick_scan_expanded.yaml", "w") as f:
    yaml.dump(stage2_cfg, f)

# Run: python -m ta_foundation.cli.main ... --report-config discovery/02_quick_scan_expanded.yaml
```

### Pattern 2: Smart (Dynamic + Cross-Family Ranking)

```python
from ta_foundation.analysis.entry_strategies.cross_family_optimizer import (
    build_unified_leaderboard,
    suggest_next_focus,
    print_leaderboard,
)

# After running all 8 families in stage 1
all_family_results = {
    "candle": candle_results,
    "ma": ma_results,
    "orb": orb_results,
    # ... etc
}

# Rank all against each other
leaderboard = build_unified_leaderboard(all_family_results, top_n=50)
print(print_leaderboard(leaderboard, top_n=20))

# Get recommendation on which to pursue
suggestion = suggest_next_focus(leaderboard, top_n_families=3)
print(f"Focus: {suggestion['focus_families']}")
# Output: Focus: ['candle', 'ma', 'orb']

# Now use dynamic expansion on ONLY the focus families
coordinator = DiscoveryStageCoordinator()
stage2_cfg = coordinator.expand_for_next_stage(1, stage1_cfg, candle_results)
# ... (do same for ma, orb)
```

### Pattern 3: Advanced (All Three Features)

```python
from ta_foundation.analysis.entry_strategies.conditional_rules import ConditionalRuleEngine
from ta_foundation.analysis.entry_strategies.stage_coordinator import DiscoveryStageCoordinator
from ta_foundation.analysis.entry_strategies.cross_family_optimizer import suggest_next_focus

# ... (run stage 1 on all families)

# Step 1: Analyze what's winning
suggestion = suggest_next_focus(leaderboard, top_n_families=3)
focus_families = suggestion["focus_families"]

# Step 2: Apply conditional rules
engine = ConditionalRuleEngine()
rules_config = yaml_config.get("conditional_rules", [])
engine.load_from_yaml(rules_config)

context = {
    "regime": "bull",  # from market analysis
    "n_trades": 150,
    "profit_factor": 1.45,
}
stage2_cfg = engine.apply(stage1_cfg, context)

# Step 3: Dynamic expansion (on the conditional result)
coordinator = DiscoveryStageCoordinator()
for family in focus_families:
    family_results = all_results[family]
    family_cfg = coordinator.expand_for_next_stage(1, stage2_cfg, family_results)
    # ... save or use

# Stage 2 is now:
#  - Focused on winners (cross-family)
#  - Adapted to market conditions (conditional)
#  - With smart parameter ranges (dynamic)
```

### Example 2: With Conditional Rules

```yaml
# discovery_with_rules.yaml

conditional_rules:
  - name: "Bull market: use candles only"
    condition: "regime == 'bull'"
    action: "enable_family"
    family: "candle_discovery"

  - name: "Flat market: use ranges"
    condition: "regime == 'flat'"
    action: "enable_family"
    family: "level_discovery"

  - name: "Skip low-trade patterns"
    condition: "n_trades < 50"
    action: "disable_pattern"
    family: "candle_discovery"
    pattern: "inside_bar"

  - name: "Expand the winners"
    condition: "profit_factor > 1.3"
    action: "expand_params"
    family: "candle_discovery"
    expansion_factor: 2.0

candle_discovery:
  enabled: true
  patterns:
    large_body:
      body_multiplier: [1.5]
    # ... will be expanded by rule if PF > 1.3
```

## Troubleshooting

### Q: "No recommendations generated"
**A:** Lower `min_pf_threshold` from 1.2 to 1.0 to see all families.

### Q: "Parameters not expanding"
**A:** Check parameter names match between YAML and results. Fix with:
```python
# Debug: print what params vary
rec = recommend_param_expansion(results)
for fam, info in rec["recommendations"].items():
    print(f"{fam}: {info['expand']}")
```

### Q: "Conditional rules not applying"
**A:** Check condition syntax. Must be valid Python expression:
```yaml
# ✅ Valid
condition: "regime == 'bull' and n_trades > 50"

# ❌ Invalid
condition: "regime is bull"  # Use == not is
condition: "regime = 'bull'"  # Use == not =
```

### Q: "Want different expansions per stage?"
**A:** Set `expansion_factor` per stage:
```python
# Stage 1→2: modest
stage2 = coordinator.expand_for_next_stage(1, cfg, results, expansion_factor=1.3)

# Stage 2→3: aggressive
stage3 = coordinator.expand_for_next_stage(2, cfg, results, expansion_factor=2.0)
```

## Performance Tips

### Reduce Runtime
```python
# Limit top N to analyze (instead of all 250)
leaderboard = build_unified_leaderboard(results, top_n=30)

# Use lower expansion factor (faster, more conservative)
stage2_cfg = generate_expanded_config(cfg, results, expansion_factor=1.2)
```

### Reduce Parameter Space
```yaml
# Stage 2: focus on TP/SL only
candle_discovery:
  patterns:
    large_body:
      body_multiplier: [1.5]  # Fix (don't vary)
      lookback: [10]          # Fix
  outcome:
    ticks:
      take_profit: [10, 20, 30, 40, 50]  # Vary
      stop: [5, 10, 15]                   # Vary
```

### Parallel Discovery
```python
from concurrent.futures import ThreadPoolExecutor

# Run families in parallel
with ThreadPoolExecutor(max_workers=4) as ex:
    futures = {
        ex.submit(run_candle_discovery, bars, cfg): "candle",
        ex.submit(run_ma_discovery, bars, cfg): "ma",
        ...
    }
    results = {name: f.result() for f, name in futures.items()}
```
