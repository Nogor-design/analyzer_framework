## Conventions for future docs

- The doc-of-record for any active program is in `docs/designs/`. The
  root-level `*.md` is **archival** unless explicitly listed canonical
  above.
- When superseding a doc, add a `> **STATUS: SUPERSEDED (date)** — see
  <path>` banner at the very top *before* anything else. Do not delete
  superseded docs; the diff is the audit trail.
- Update this index when adding or retiring a doc. If you are an AI
  agent touching docs, the change to `DOCS_INDEX.md` is part of the
  same edit, not a follow-up.
